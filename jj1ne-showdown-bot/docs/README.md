# Project Documents Folder (`docs/`)

Any markdown (`.md`) or text (`.txt`) file placed in this folder will automatically be read by the **Coach (`coach.js`)** during post-game reviews and by **Chat Mode (`chat.js`)** when answering your questions!

### Examples of files you can drop here:
- Metagame analysis notes
- Target damage calculations & speed benchmarks
- Tournament regulations or bans
- New team theorycrafts or archetype counter strategies
